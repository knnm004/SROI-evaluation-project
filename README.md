## 🤝 How to Collaborate

All active development happens on the `develop` branch. 

**First time setup for coworkers:**
1. Clone the repository: `git clone https://github.com/knnm004/sroi-evaluation-app.git`
2. Move into the folder: `cd sroi-evaluation-app`
3. Switch to the develop branch: `git checkout develop`
4. Install dependencies: `npm install`
5. Run the server: `npm run dev`

**When making daily changes:**
1. **Pull the latest code** before you start working: `git pull origin develop`
2. **Make your edits** and test them.
3. **Commit your changes:**
   ```bash
   git add .
   git commit -m "Describe what you changed here"
